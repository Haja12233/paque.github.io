Bienvenue sur **Pâques.github.io**, un site web **festif** et **symbolique** conçu pour célébrer la **fête de Pâques** à travers une expérience visuelle chaleureuse et immersive.

🌐 Accéder au site :  
**https://haja12233.github.io/paque.github.io/**

---

## 🎯 Objectif du Site

Ce projet a été créé pour :

- ✨ Transmettre des vœux de Pâques de manière moderne et interactive  
- 💖 Partager un message de **joie, d’espoir et de renouveau**  
- 🎨 Offrir une expérience visuelle agréable et festive  
- 🧑‍💻 Montrer les compétences en développement web front-end à travers un projet créatif  

Ce site peut être utilisé pour :
- Souhaiter **Joyeuses Pâques** à ses proches  
- Créer une **ambiance festive en ligne**  
- Servir de modèle pour des **cartes de vœux numériques**

---

## 🧭 Fonctionnement du Site

- L’utilisateur accède directement à une **interface décorée et festive**  
- Un message de Pâques est affiché avec des éléments visuels attractifs  
- Des animations et effets rendent l’expérience **plus vivante et immersive**  
- Aucun formulaire ni configuration : l’expérience est **immédiate et fluide**

---

## ✨ Expérience Utilisateur

- 🌈 **Design festif** : couleurs joyeuses, éléments visuels liés à Pâques (œufs, décorations, etc.)  
- 🎬 **Animations fluides** : effets dynamiques pour captiver l’utilisateur  
- 📱 **Responsive design** : adapté à tous les écrans (mobile, tablette, PC)  
- 💡 **Navigation simple** : accès direct sans complexité  

---

## 💡 Pourquoi ce Projet est Intéressant ?

- 💖 **Impact émotionnel fort** : transmet des messages positifs et chaleureux  
- 🎯 **Simplicité efficace** : une idée simple mais bien exécutée  
- 🌐 **Accessibilité totale** : fonctionne sur tous les navigateurs modernes  
- 🧑‍💻 **Démonstration technique** : utilisation maîtrisée de HTML, CSS et JavaScript  

Ce projet montre qu’un site web peut être à la fois **simple, beau et porteur de sens**.
